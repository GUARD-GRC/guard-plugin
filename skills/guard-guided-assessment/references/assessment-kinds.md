# Assessment kinds (GUARD)

| `kind` | Subject | What it is for | At the end |
| --- | --- | --- | --- |
| `company_assessment` | the whole organisation | governance across the company: policies, accountability, data, staff skills, use of AI tools including unapproved ("shadow") AI | report + gaps + duty coverage |
| `ai_system_assessment` | one AI system (needs `ai_system_id`) | that system's purpose, data, autonomy, people affected, jurisdictions, safeguards | report + gaps + duty coverage + GUARD's classification of the system |
| `company_setup` | the business profile | fills the profile by questions (name, website, jurisdictions, where the company is registered, unapproved AI use, description) | answers saved to the business profile; GUARD starts a fresh profile summary |

## Before you choose
- If the business profile is thin, GUARD pre-fills less. Filling the profile first (a company setup) saves time.
- An AI-system assessment reuses what GUARD already knows from the profile and earlier assessments.

## Key questions (the person confirms them)
These decide the classification or which questions follow. GUARD takes the person's own words first and proposes options; the person confirms the ones that fit:
- where the system is used or affects people (jurisdictions);
- the organisation's role: uses a third-party system, built it, sells it inside a product, or both;
- how much a person checks the output (autonomy);
- which kinds of data it uses;
- whether it is used for a prohibited purpose (this ends the assessment early with a prohibited-use result);
- whether the organisation is a financial-services firm (adds financial-regulator questions).

## The five GUARD pillars (used for gaps)
- **G**: Governance
- **U**: Unauthorized Data Access
- **A**: Attrition of Skills
- **R**: Reputation
- **D**: Dollar Drain

## Duty coverage
For each binding regulation GUARD keeps a duty register for, the report records each duty as addressed, not addressed, or not applicable. Coverage appears only for registers GUARD has switched on. If there is none, say that coverage is not available for this assessment.
